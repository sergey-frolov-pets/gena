# Серверная часть Gena — план (2026-11-26)

_Основание: задача Сергея от 26.11.2026. Ветка `feat/gena-server`._

## Что делаем

1. **Сервер** `server/` — один Go-бинарник без внешних зависимостей:
   - хранит диалоги и сообщения (JSON-файлы, атомарная запись);
   - токен доступа (Bearer), CORS для SPA;
   - ставится на сервер к агенту или на любой другой сервер;
   - Docker + systemd + `install.sh`.
2. **Клиент**:
   - «Добавить сервер Gena» в «Подключениях» (имя, адрес, токен, проверка связи);
   - серверные сессии: кнопка в хедере чата, выбор сервера, если их несколько;
   - «Сохранить сессию в md» — скачивание файла (локально, без сервера).
3. **Меню**: «Баланс» отдельным пунктом (деньги провайдеров + цены моделей), из «Подключений» убрать.
4. **«О программе»**: две инструкции — для агента (готовый промпт) и для человека (шаги).

## Хедер чата

Было: название = кнопка, клик → inline-input + «Сохранить».
Стало: название текстом, рядом всегда `✏️`; затем `＋ серверная сессия` (один сервер — сразу,
несколько — выбор) и `⤓ в md`.

## Сервер: API (v1.0.0)

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/health` | без токена: имя, версия, время |
| GET | `/api/server` | имя, версия, число сессий |
| GET | `/api/sessions` | список (pinned → updatedAt) |
| POST | `/api/sessions` | создать `{title, agentId}` |
| GET | `/api/sessions/{id}` | сессия + сообщения |
| PATCH | `/api/sessions/{id}` | `{title,pinned,tags}` |
| DELETE | `/api/sessions/{id}` | удалить |
| POST | `/api/sessions/{id}/messages` | добавить сообщение |
| PATCH | `/api/sessions/{id}/messages/{msg}` | правка текста |
| DELETE | `/api/sessions/{id}/messages/{msg}` | удалить сообщение |
| POST | `/api/sessions/{id}/import` | полная синхронизация сессии с клиента |
| GET | `/api/sessions/{id}/export.md` | markdown-файл |

## Этапы

- **M1** сервер + тесты + установка + документация.
- **M2** клиент: серверы в IndexedDB, API-клиент, серверные сессии, хедер, md.
- **M3** «Баланс» отдельной вкладкой, «Добавить сервер Gena», «О программе».
