# Чат: все диалоги, фильтр чипами, параллельные ходы (22.11.2026)

Решение Сергея: история — не «по агенту», а все диалоги с фильтром; новая сессия
открывается с полем ввода; реплика из нового диалога не встаёт в чужую очередь —
у каждого диалога свой ход и своя очередь. Ломать обратную совместимость можно,
все проверки должны быть зелёными.

## Что изменилось

- **История и вкладки.** `ChatView` больше не фильтрует сессии по выбранному агенту:
  показываются все, у строки — имя её агента. Открытие диалога другого агента
  переключает `agentId`, чтобы шапка и стандартные сообщения были от его агента.
- **Фильтр.** Чипы «Все агенты» + агенты, у которых есть диалоги (в истории чата
  и на вкладке «Сессии»). Логика одна — `composables/useAgentFilter.ts`.
  «Выбрать все» на странице сессий работает по видимому списку.
- **Новый диалог.** На телефоне поле ввода открывается сразу (и после закрытия
  последнего диалога), фокус ставится после `newSession()`.
- **Параллельные ходы.** `busy`/`typing`/`streamingText`/`turnStartedAt` заменены
  на состояние по диалогам (`composables/useLiveTurns.ts`). До 3 одновременных
  ходов; четвёртая реплика ждёт, пока освободится слот.
- **Очередь по диалогам.** Панель очереди показывает только реплики открытого
  диалога; планировщик (`lib/turn-queue.ts`, `pickRunnable`) отдаёт каждому
  диалогу его первую реплику и пропускает диалог, который только что упал.
  «Отправить сейчас» хранится по диалогу и останавливает ход именно его.
- **Ошибки фоновых диалогов** не всплывают поверх открытого чата: хранятся по
  сессии (`sessionErrors`) и показываются, когда человек откроет диалог.
  Озвучка и подсказки — тоже только для открытого диалога.

## Рефакторинг

- `src/composables/useLiveTurns.ts` — состояние ходов по сессиям, таймер счётчика,
  открытие/правка/закрытие хода, накопление стрима.
- `src/composables/useAgentFilter.ts` — фильтр списка по агенту (чипы, сброс при
  удалении агента).
- `src/lib/turn-queue.ts` — чистые правила: занят ли диалог, сколько ходов идёт,
  какую реплику очереди можно взять сейчас.
- Тесты: `useLiveTurns.test.ts` (4), `useAgentFilter.test.ts` (4),
  `turn-queue.test.ts` (8). Всего **451** тест.
