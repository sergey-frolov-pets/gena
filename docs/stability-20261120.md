# Стабильность Gena — что сделано и что можно поменять

_2026-11-20. Разбор по коду ChatView / pico-ws / service worker._

## Уже сделано в этой правке

| Мера | Зачем |
|---|---|
| `navigator.storage.persist()` при старте | IndexedDB не вычищается браузером при нехватке места |
| Черновик в `localStorage` на диалог + `pagehide` | Закрыл вкладку — текст на месте |
| `pending`-ход в `localStorage` + догон при открытии/возврате | Ответ не теряется, если приложение закрыли до ответа |
| `beforeunload` при активном ходе | Браузер предупредит о закрытии во время генерации |
| `online`/`offline` + предупреждение | Понятно, почему ответ не пришёл |
| `visibilitychange` → догон | Вернулись на вкладку — ход продолжается |
| `skipWaiting` + `clients.claim` (SW) | Новая сборка подхватывается без «залипания» старой |

## Что стоит поменять дальше (по приоритету)

2. **Серверный resume вместо повторной отправки.** Pico не отдаёт историю по `session_id`; догон — это повторный `message.send`, он дублирует реплику в контексте агента. Нужен кадр `message.history` / `turn.resume` в `pkg/channels/pico` (Go). Сборка Go на этой машине пока OOM — отложено.
4. **Очередь и вложения: лимит хранения.** `localStorage` ~5 МБ; data-URL картинок туда не кладём. Для вложений — только миниатюры (уже так), плюс периодическая очистка осиротевших blob-URL.
5. **Оценка хранилища.** `navigator.storage.estimate()` → предупреждение «мало места» до того, как IndexedDB начнёт падать с `QuotaExceededError`.
10. **Отмена на сервере.** «Стоп» рвёт WebSocket; генерация на сервере может продолжаться. Кадр `cancel` (или HTTP `/cancel`) сэкономит токены и время.

## Что проверить руками

- Телефон: тап по чату → ввод поверх; отправка/потеря фокуса → ввод исчезает; черновик возвращается после перезагрузки.
- Телефон: отправить длинный запрос, закрыть приложение, открыть снова — ответ появляется (повторная отправка).
- Десктоп: ввод всегда на месте, поведение не изменилось.
- Размышления: несколько `thought` одного хода — один свёрнутый блок со счётчиком.
- Роль: у Pico-агента — его имя, у OpenAI-подключения — `model (LLM)`.
